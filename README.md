# gg — ドメインチェック v0.2.0

Google Workspace の申込画面を操作する Chrome / Edge 拡張です。
ドメインを入力し、Enter または右側の矢印で確認します。結果は「ドメインチェックOK」「既存利用の表示あり」「未確認」のいずれかです。

## インストール・更新

1. 配布ZIPをダウンロードして展開します。GitHubに掲載された版は「Code → Download ZIP」から取得できます。
2. Chromeの `chrome://extensions` またはEdgeの `edge://extensions` でデベロッパーモードを有効にします。
3. 初回は「パッケージ化されていない拡張機能を読み込む」で `manifest.json` のあるフォルダを指定します。
4. 更新時は既存フォルダの中身を修正版に置き換え、拡張一覧の再読み込みボタンを押します。以前のチェック画面とGoogle申込タブを閉じ、ggを開き直してください。

利用時にNode.jsやサーバー、APIキーは不要です。会社管理ブラウザの拡張導入制限がある場合は管理者の許可が必要です。

## 今回の修正

- 入力欄のラベル、プレースホルダー、フォーム構造を別々に確認します。
- 連絡先が入力済みなら変更せず「次へ」を押します。空欄だけテスト値で補完します。
- 希望ドメインを入力し、「次へ」が有効になってから送信します。同じ送信は繰り返しません。
- 手動で「次へ」を押した場合も、同じ実行タブで対象ドメインを確認できていれば結果を判定します。
- 確認画面のURLが先に変わっても、本文の描画を最大20秒待ちます。
- 自動操作は5分でタイムアウトします。その後は操作せず、開始から15分以内なら同じタブの手動確認結果だけ受け付けます。
- 画面は「ドメインを入力」、フォーム、結果だけにしました。

## 判定範囲

OKは、Googleの `/business/signup/bringconfirm` に到達し、今回の対象ドメインとメールへの影響がない旨の文言を確認したという意味です。既存テナントが絶対にないことを保証しません。確認画面で停止し、その先のアカウント作成や契約操作は行いません。

日本語画面が対象です。Googleの画面変更・入力拒否・通信障害・人による確認などで未確認になる場合があります。標準の補完値は会社名・姓名が `test`、連絡先が `test@example.com`、従業員数10〜99人です。入力済みの連絡先を優先します。Googleに補完値を拒否された場合は、Googleの画面上で使用可能な連絡先に変更してください。

## データの取り扱い

- ソースには実在顧客の情報、パスワード、APIキーを含みません。提供されたスクリーンショットやその個人情報は配布物に含めていません。
- 実行タブのGoogle申込画面を読み取り、会社名・連絡先・希望ドメインをGoogleのフォームに入力・送信します。
- 実行状態と最新の結果は拡張のセッション領域だけに保存します。履歴は蓄積しません。
- PCファイル、他サイトの情報、Cookie、閲覧履歴を収集する処理や独自サーバーへの送信はありません。

## 検証

判定ロジック8件と、DOM・拡張メッセージ処理を用いた回帰テスト12件が合格しています。連絡先入力済み、ドメイン入力・クリック、描画待ち、手動補助、別タブ・別ドメインの拒否を確認しました。

**今回の修正版を実際の会社PCのGoogle画面で動かす試験は未実施です。** 最初に結果を把握しているドメインで照合してください。

開発用テストのみ `npm ci` の後 `npm test` で実行できます（Node.js 22.13以上を想定）。`package.json`、`package-lock.json`、`tests` は拡張の通常利用には不要です。
