# gg ドメインチェック

Google Workspaceでドメインが使用中か確認する拡張機能。

## 入れ方

1. Code → Download ZIP でダウンロードして展開
2. ブラウザの拡張機能画面でデベロッパーモードをON
3. 「パッケージ化されていない拡張機能を読み込む」で、manifest.jsonがあるフォルダを選択

更新するときはファイルを置き換えて、拡張機能を再読み込み。

## 使い方

ggを開いてドメインを入力 → Enter。

最近使ったドメインは5件まで表示。
履歴をクリックすると、そのまま再チェック。

## データについて

- コードに顧客情報やパスワード、APIキーは含みません。
- チェックに必要な情報をGoogleの申込画面へ送信します。
- 履歴はドメインだけ最大5件、このブラウザに保存します。
- PC内のファイルやCookie、閲覧履歴は収集しません。独自サーバーへの送信もありません。
